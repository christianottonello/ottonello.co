# ottonello.co

Personal site of Christian Ottonello. Astro, plain CSS, self-hosted Newsreader, Vercel.

- `npm install`
- `npm run dev` — local at http://localhost:4321
- `npm run build` — static output in `dist/`

Content lives in `src/content/` (writing, photos) once those sections exist. v1 is a single page.
